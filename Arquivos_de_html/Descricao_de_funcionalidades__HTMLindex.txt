    LINKS ABSOLUTOS E RELATIVOS
__________________________________

Tag <a></a>: serve pra colocar um link na pagina
exemplo:
<a href="Caminho ou link"></a> na pratica veja o arquivo (Links_index.html) da pasta (Programacao_Web_do_Zero_ao_Avançado), se quiseres que ele abra numa outra janela, coloque assim: <a href="https://google.com" target="_blank"></a>

Para que abra link absoluto: <a href="https://google.com" target="_blank"></a>
Para que abra link relativo: <a href="nome de um arquivo html" target="_blank"></a>
Se estiver em pasta diferente usa-se: <a href="nome da pasta/nome do arquivo html" target="_blank"></a>

OBS: Só podes voltar pra uma pagina de um dos arquivos caso estiverem na mesma pasta!
pra tal, tem que se escrever : <a href="../nome do arquivo html" target="_blank"></a>
Os (..) indicam que voltou 1 pasta pra aceder a um arquivo pelo link establecido
Exemplo: <a href="../Exemplo_usado_no_arquivo_Links_index.html" target="_blank"></a>
(../../../) caso o arquivo html esteja várias pastas atrás.

        Formularios
_____________________________
Sobre ele: Nesta aula do nosso curso de HTML completo vamos aprender como usar os formulários. Os formulários HTML são muito importantes por que é com eles que você recebe entrada de dados. Praticamente tudo o que você utiliza na programação web depende de formulários.

Sua tag principal é a tag: <form></form>

    <form>

        SOBRE O TIPO TEXTO:

        <label for="campo_nome">Nome:</label>
        <input id="campo_nome" type="text" placeholder="Digite o seu nome"><br><br>

        SOBRE O TIPO PASSWORD:

        <label for="campo_senha">Senha:</label>
        <input id="campo_senha" type="password" placeholder="Digite uma senha"><br><br>

        SOBRE O TIPO EMAIL:

        <label for="campo_email">Email:</label>
        <input id="campo_email" type="email" placeholder="Digite o seu email"><br><br>

        SOBRE O TIPO SUBMIT:


        <input type="submit" value="Enviar formulário"><br><br>

        «SOBRE O RADIO»

        <input type="radio" name="clima" id="Solarado" value="Solarado">
        <label for="Solarado">Solarado</label><br>

        <input type="radio" name="clima" id="Chuvoso" value="Chuvoso">
        <label for="Chuvoso">Chuvoso</label><br>

        <input type="radio" name="clima" id="Nublado" value="Nublado">
        <label for="Nublado">Nublado</label><br>

        
    </form>

O for="" funciona junto com id pra ligar o input a uma label (texto).

o submit serve pra enviar o formulario.

o required é um atributo do campo input.

o radio é como uma lista de seleção unica, mas pra isso acontecer, é necessário que os inputs tenham os mesmo name="", mas id="" e value diferentes !
Ex de categoria animal.:

OBS: O valor do ID e do Value pode ser igual.
Mas cada elemento da pagina deve ter apenas um único ID.

Pra tornar o radio com uma só escolha, basta colocar o mesmo name="", caso não estraga a finalidade da do metodo ou função.

Se for ogg usa-se ogg
